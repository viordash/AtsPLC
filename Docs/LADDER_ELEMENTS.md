# Элементы Ladder Diagram

Программа - список сетей (networks). Сеть - цепочка элементов слева направо: от входной шины
к выходной. Каждый элемент получает состояние предыдущего и отдаёт своё дальше.

Ограничения: 1..80 сетей в программе, 1..5 элементов в сети, на экране видно 2 сети.

Адреса ввода-вывода: `DI` (дискретный вход), `AI` (аналоговый вход), `O1`, `O2` (выходы),
`V1`..`V4` (переменные).

## Входы (Inputs)

| Элемент | Описание |
|---------|----------|
| **InputNO** | нормально разомкнутый контакт: пропускает, когда значение адреса не равно 0 |
| **InputNC** | нормально замкнутый контакт: пропускает, когда значение адреса равно 0 |
| **TimerSecs** | задержка в секундах, 1..99999 |
| **TimerMSecs** | задержка в миллисекундах, 50..99950 с шагом 50 |
| **SquareWaveGenerator** | генератор импульсов, задаются длительности паузы и импульса |
| **ComparatorEq / Ne / GE / Gr / LE / Ls** | сравнение значения адреса с уставкой |
| **Indicator** | показывает значение адреса с масштабированием и десятичной точкой |

Таймер начинает отсчёт, когда предыдущий элемент стал активным, и пропускает сигнал по
истечении времени. Смена состояния предыдущего элемента сбрасывает отсчёт.

## Выходы (Outputs)

| Элемент | Описание |
|---------|----------|
| **DirectOutput** | пишет 255 при активном входе, 0 при пассивном |
| **SetOutput** | пишет 255 при активном входе, защёлка |
| **ResetOutput** | пишет 0 при активном входе |
| **IncOutput** | увеличивает значение на 1, потолок 255 |
| **DecOutput** | уменьшает значение на 1, пол 0 |

Выходной элемент завершает цепочку и рисуется у правой шины.

## Переходы между цепями (Flow)

| Элемент | Описание |
|---------|----------|
| **ContinuationOut** | завершает сеть, передавая её состояние следующей |
| **ContinuationIn** | начинает сеть состоянием, переданным предыдущей |

Пара позволяет собрать цепочку длиннее пяти элементов, разложив её на несколько сетей.

## Привязки (Bindings)

Привязка связывает переменную с внешним источником: пока привязка активна, переменная
отражает состояние источника.

### WiFiBinding

Ищет в эфире сеть с заданным SSID и кладёт в переменную уровень сигнала, приведённый к
0..255. Ноль означает, что сеть не найдена.

### WiFiStaBinding

Подключает устройство к сохранённой WiFi-станции и кладёт в переменную уровень сигнала.
При подключении поднимается web-сервер.

### WiFiApBinding

Поднимает точку доступа с заданными SSID и паролем и кладёт в переменную число подключённых
клиентов. Маска MAC отбирает, кого считать своим: символ `*` в позиции означает "любой".

### DateTimeBinding

Кладёт в переменную часть текущего времени: секунду, минуту, час, день, день недели, месяц
или год. Элемент сам просит контроллер просыпаться с нужным периодом.

## Элемент настроек (SettingsElement)

Показывает и редактирует одно поле настроек устройства прямо в цепочке: параметры
WiFi-станции, сканера, точки доступа, SNTP, ADC, текущие дату и время. Пока элемент не
активен, значения даты и времени показываются прочерками.

## Режимы редактирования

Редактирование доступно в режимах Stop и Debug, см. [WORK_MODES.md](WORK_MODES.md).

### Базовое редактирование

Select на главном экране выбирает сеть, следующий Select входит в неё, дальше Вверх/Вниз
переключают элементы и их параметры, Select подтверждает.

### Расширенные режимы

Долгое нажатие Select на выбранной сети открывает действия над сетью целиком:

| Действие | Что делает |
|----------|------------|
| Move | перемещение сети вверх/вниз |
| Copy | дублирование сети |
| Delete | удаление сети |
| Disable | выключение сети без удаления |

Выключенная сеть рисуется со штриховой входной шиной и не исполняется.

## Технические детали

### Цикл контроллера

За один цикл: опрос входов, обход всех сетей (`Ladder::DoAction`), запись выходов. Цикл
ограничен по времени; если работы больше, она продолжается на следующем проходе.

### Приоритеты пробуждения

Элементы просят контроллер разбудить их через заданное время. Запрос критического
приоритета (таймеры, генератор) исполняется точно; запрос холостого приоритета (мигание
курсора, обновление индикатора) может быть склеен с ближайшим соседним, чтобы не будить
контроллер лишний раз.

### Хранение

Программа сериализуется в бинарный вид по типу элемента (`TvElementType`) и пишется через
`redundant_storage` в два раздела сразу. Вместе с сетями в файл пишется режим работы.
